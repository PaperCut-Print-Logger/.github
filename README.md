## 🚀 Why Choose PaperCut Print Logger?

Usage arguments need data. The logger captures who printed what to which device, so a chargeback or a reduction plan starts from real numbers.

CSV export feeds spreadsheets without retyping.

## 🎮 Why Use It?

- **See who prints most**
- **Estimate costs** per device
- **Review page counts**
- **Export reports**
- **Track changes** over time

## 🧩 Quick Start

1. Install the logger on the print server.
2. Let it record for a period.
3. Filter by printer or user.
4. Review the summary.
5. Export CSV for the report.
